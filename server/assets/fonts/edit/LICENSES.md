# Caption / card fonts — licences

All files in this directory are static (non-variable) fonts licensed under the **SIL Open Font License 1.1 (OFL-1.1)**.
Each family's licence text is stored next to it (`OFL-<Family>.txt`, copied verbatim from `google/fonts` `ofl/<family>/OFL.txt`).
The OFL permits bundling, embedding (burned-in captions, base64 `@font-face` in HyperFrames cards) and redistribution with
software; the fonts must not be sold by themselves and modified versions must not use the Reserved Font Names.
`manifest.json` lists the name-table family (ID 1, Windows en-US — the exact ASS `Fontname`), OS/2 weight, covered scripts
(ISO 15924), sha256 and size. Retrieved 2026-09-14.

## ASS usage notes (verified by spike S3)

- `Fontname` must be the family above (name ID 1). The full name (ID 4, e.g. "Archivo Black Regular") also matches; the
  PostScript name (e.g. "ArchivoBlack-Regular") does NOT match a fontsdir font and silently falls back to a system font (ArialMT).
- Use ASS `Bold` = 0 for the weight-400 files (Archivo Black, Anton) and -1 for the weight-700 files.
- `NotoSansDevanagari-Bold.ttf` and `NotoSansArabic-Bold.ttf` have no Basic Latin letters — Latin words inside hi/ar captions need
  an explicit `\fn` switch to a Latin family from this directory, otherwise libass silently falls back to a system font.
