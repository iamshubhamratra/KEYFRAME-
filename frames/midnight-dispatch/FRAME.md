# Midnight Dispatch

Late-night broadcast slate: ink ground, condensed bone-white headlines that snap on the beat, one hot amber accent and an anchor blue doing all the wiring.

## Palette

| Role | Hex | Job |
|---|---|---|
| `ink` | `#05070a` | Primary ground and the only ink used on light or blue plates |
| `carbon` | `#0f141b` | Secondary panel ground — stats plate, montage tiles, app shell |
| `midnight` | `#0a2d52` | Deep navy statement ground, derived from the anchor blue |
| `signal` | `#0d77e7` | Anchor accent — chip outlines, card frames, tile rules, data columns |
| `amber` | `#ffb020` | The one hot accent: kicker, emphasis, counters, CTA button |
| `paper` | `#f5f2ea` | Bone-white copy on dark grounds; feature-beat ground |
| `ash` | `#8d97a5` | Hairlines and muted UI chrome only, never body copy |

## Rhythm

hook (ink) → statement (midnight) → feature (paper, light break) → montage (ink) → stats (carbon) → cta (ink). World scanlines appear only on hook, stats and cta so the backdrop reads as punctuation, not wallpaper. Cuts are hard; no crossfades, no drop shadows, one line per headline.
