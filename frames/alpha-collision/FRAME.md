# Alpha collision

Alpha collision is a Swiss-grid motion skin: one electric lime accent, an electric-violet counter-ground, Poppins throughout, and a backdrop of ruled lines, a raking beam and drifting bloom that never fully stops moving.

## Palette

| Role | Hex | Job |
|---|---|---|
| `void` | #060b09 | Primary dark ground — hook, montage, CTA |
| `graphite` | #16211c | Tiles, app shell, secondary panels |
| `pine` | #0b3b28 | Saturated ground for the stats beat |
| `lime` | #28f02c | The one accent — highlights, glow, buttons, tile rules |
| `ultra` | #4b3bff | Counter-accent — statement ground, highlight on light beats |
| `paper` | #f2f7f2 | Light ground and primary text on dark |
| `ink` | #050807 | Text on light grounds, screenshot card plate |

## Beat rhythm

dark → violet → light → dark → pine → dark. Feature is the only light beat, so the hero screenshot card sits on paper with an ink plate and lime glow; every other beat runs light type on dark ground.
