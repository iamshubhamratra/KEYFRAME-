# Daylight Console

Light-ground editorial layout for software promos: warm paper, ink serif headlines in a narrow measure sized to survive long scripts, and screenshots placed as softly shadowed detail-crop cards beside the copy column — with the accent blue painted solid in chips, buttons and counters.

## Palette

| Role | Hex | Used for |
|---|---|---|
| `paper` | `#F7F4EE` | primary warm off-white ground; hook, feature, stats, app |
| `linen` | `#EFEAE1` | second ground for statement, montage and CTA; card and tile fills |
| `ink` | `#14161A` | all body and display type, tile labels |
| `slate` | `#4A4F57` | hairline rules, grid layer, third chip |
| `indigo` | `#2A4BD8` | the painted accent — filled kicker pill, filled chips, CTA block, tile edges, counters, beam |
| `clay` | `#B0532A` | warm counter-accent — second chip, dust motes, one stat |
